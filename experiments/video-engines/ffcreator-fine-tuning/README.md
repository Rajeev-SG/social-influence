# FFCreator: What is fine-tuning?

A 23.07-second beginner explainer built with FFCreator. It teaches that
fine-tuning gives an already-trained model a focused course in curated examples
and feedback, adapting selected behavior without starting over.

## Deliverables

- `deliverables/final.mp4`: 1080x1920, 30 fps, H.264/yuv420p, stereo AAC.
- `deliverables/preview.mp4`: 540x960 review copy.
- `deliverables/contact-sheet.jpg`: representative frames from all five scenes.

## Source map

- `src/film.js`: FFCreator scene construction, kinetic typography, diagrams,
  captions, transitions, and cue timing.
- `src/timing.json`: measured Kokoro cue timing generated by `scripts/narrate.cjs`.
- `assets/script.json`: original narration script.
- `assets/visuals/`: generated local diagram and icon layers.
- `assets/audio/`: Kokoro reference clips, narration, procedural soundscape, and mix.
- `scripts/build-assets.mjs`: generates the visual layers.
- `scripts/narrate.cjs`: local Kokoro 82M q8 ONNX synthesis.
- `scripts/soundscape.py`: original procedural stereo score and effects.
- `scripts/render.cjs`, `scripts/render.sh`: FFCreator render entrypoints.
- `scripts/inspect_media.py`: extracted-frame and audio synchronization QA.
- `scripts/package_media.sh`: preview and contact-sheet packaging.
- `scripts/verify_media.py`: final media contract gate.

## Reproduce

The project uses the already-installed Kokoro cache and `bf_emma` voice:

- model cache:
  `/Users/rajeev/Code/content-machine/node_modules/@huggingface/transformers/.cache/onnx-community/Kokoro-82M-v1.0-ONNX`
- voice:
  `/Users/rajeev/Code/content-machine/node_modules/kokoro-js/voices/bf_emma.bin`

No TTS weights are downloaded by these scripts.

```sh
npm install
node scripts/build-assets.mjs
node scripts/narrate.cjs
python3 scripts/soundscape.py
./scripts/mix_audio.sh
./scripts/render.sh
python3 scripts/inspect_media.py
./scripts/package_media.sh
python3 scripts/verify_media.py
```

`ffcreator@7.5.8` is the current npm release used here. The maintained source
tree currently labels itself `8.0.1`, but npm does not publish that tag. The
package's `canvas` and `gl` native dependencies were built locally for Node 26;
the temporary `node_modules` tree is intentionally not retained.
